# KHO TÀI LIỆU MÔN ỨNG DỤNG THUẬT TOÁN - HAUI

## Giới thiệu
Đây là kho chứa các kiến thức tổng hợp được từ môn học. Chúc các bạn học thật tốt, mang về nhiều A 

## Mô tả các file
| Dạng File       | Mô Tả                                                                                        |
|-----------------|----------------------------------------------------------------------------------------------|
| '.cpp'          | File code bài giải chạy cho các bài tập và một số bài khác                         |
| '.pdf'          | Các file slide bài giảng trên lớp và các bài thực hành (nguồn từ thầy, cô trên lớp)          |
| '.png, .jpg'    | Các file ảnh là các đề kiểm tra thường xuyên và kết thúc học phần sưu tầm được từ bạn bè|
| '.xlsx'         | Các file excel mô tả, chạy chậm thuật toán                                   |
| '.txt'          | Các ghi chú về thuật toán                                                      |
